Guide d'installation
Étape 1 — Créer la base Supabase
1. Va sur supabase.com → New project
2. Dans "SQL Editor", colle et exécute le SQL ci-dessous
3. Dans "Project Settings" → API → copie l'URL et la clé anon
-- Profils utilisateurs -- Table pour les alias (optionnel, fonctionne aussi sans via localStorage) create table aliases ( id uuid default gen_random_uuid() primary key, alias_text text not null, user_id uuid references auth.users not null, created_by uuid references auth.users, created_at timestamptz default now() ); alter table aliases enable row level security; create policy "Aliases lisibles par tous les membres" on aliases for select using (auth.uid() is not null); create policy "Membres peuvent créer des alias" on aliases for insert with check (auth.uid() = created_by); create table profiles ( id uuid references auth.users primary key, username text, boards text[], created_at timestamptz default now() ); alter table profiles enable row level security; create policy "Users can manage own profile" on profiles for all using (auth.uid() = id); -- Sessions de surf create table sessions ( id uuid primary key default gen_random_uuid(), user_id uuid references auth.users not null, date date not null, spot text, launch_point text, context text, duration_h float, hs float, period float, swell_dir text, wind_kts float, wind_dir text, tide text, board text, price_cfp int, quality int, moves text[], shared_with text[], observations text, is_shared boolean default false, created_at timestamptz default now() ); alter table sessions enable row level security; create policy "Users see own sessions and shared" on sessions for select using (auth.uid() = user_id or is_shared = true); create policy "Users manage own sessions" on sessions for all using (auth.uid() = user_id); -- Commentaires sur sessions partagées create table session_comments ( id uuid primary key default gen_random_uuid(), session_id uuid references sessions not null, user_id uuid references auth.users not null, username text, quality int, comment text, created_at timestamptz default now() ); alter table session_comments enable row level security; create policy "Anyone can read comments" on session_comments for select using (true); create policy "Users manage own comments" on session_comments for all using (auth.uid() = user_id);
Étape 2 — Configurer le fichier HTML
Ouvre surf-journal.html et remplace les deux lignes en haut :
const SUPABASE_URL = 'https://xxxxx.supabase.co';
const SUPABASE_KEY = 'eyJhbGc...';
Étape 3 — Mettre en ligne (Netlify)
1. Va sur netlify.com → "Add new site" → "Deploy manually"
2. Glisse-dépose ton fichier surf-journal.html
3. Partage l'URL avec tes potes !
