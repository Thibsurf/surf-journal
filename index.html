▶ 🧩 Extension Chrome — Installation & fonctionnement
Pourquoi l'extension ?
meteo.nc requiert un token JWT (valide ~22min) pour accéder aux prévisions. L'extension le capte automatiquement dès que tu visites meteo.nc, le stocke dans Chrome, et le synchronise vers le Worker Cloudflare pour tous tes appareils. Elle se renouvelle seule toutes les 20min en ouvrant brièvement un onglet meteo.nc en arrière-plan (normal — l'onglet se ferme tout seul). Badge vert dans le popup = tout roule.
1
Télécharger l'extension
⬇ nc-token-extension-v10.zip — dézipper dans un dossier.
2
Charger dans Chrome
Ouvre chrome://extensions → activer le Mode développeur → Charger l'extension non empaquetée → sélectionner le dossier dézippé.
3
Premier token
Visite meteo.nc une fois. L'extension capte le token automatiquement et le pousse vers Supabase. Badge 🔑 vert = token actif. Le statut ci-dessous se met à jour automatiquement.
↺
Renouvellement automatique
L'extension renouvelle le token toutes les 20min automatiquement — un onglet meteo.nc s'ouvre brièvement en arrière-plan puis se referme (c'est normal). Si tu as déjà un onglet meteo.nc ouvert, il est simplement rechargé. Si le badge devient rouge : clique "Capturer / Renouveler" dans le popup de l'extension.
Sans extension — tu peux coller le token manuellement :
DevTools (F12) → Network → une requête rpcache.meteo.nc → Headers → Authorization: Bearer eyJ… → copier la partie après "Bearer ".

Guide d'installation
Étape 1 — Créer la base Supabase
1. Va sur supabase.com → New project
2. Dans "SQL Editor", colle et exécute le SQL ci-dessous
3. Dans "Project Settings" → API → copie l'URL et la clé anon
-- Profils utilisateurs -- Table pour les alias (optionnel, fonctionne aussi sans via localStorage) create table aliases ( id uuid default gen_random_uuid() primary key, alias_text text not null, user_id uuid references auth.users not null, created_by uuid references auth.users, created_at timestamptz default now() ); alter table aliases enable row level security; create policy "Aliases lisibles par tous les membres" on aliases for select using (auth.uid() is not null); create policy "Membres peuvent créer des alias" on aliases for insert with check (auth.uid() = created_by); create table profiles ( id uuid references auth.users primary key, username text, boards text[], created_at timestamptz default now() ); alter table profiles enable row level security; create policy "Users can manage own profile" on profiles for all using (auth.uid() = id); -- Sessions de surf create table sessions ( id uuid primary key default gen_random_uuid(), user_id uuid references auth.users not null, date date not null, spot text, launch_point text, context text, duration_h float, hs float, period float, swell_dir text, wind_kts float, wind_dir text, tide text, board text, price_cfp int, quality int, moves text[], shared_with text[], observations text, is_shared boolean default false, created_at timestamptz default now(), boat_id uuid references boats, spots text[], distance_nm float, tube_count int, bateau text, forecast_accuracy int, tide_ranges jsonb, tide_port text, from_sortie_id uuid, nb_surfers smallint ); alter table sessions enable row level security; create policy "Users see own sessions and shared" on sessions for select using (auth.uid() = user_id or is_shared = true); create policy "Users manage own sessions" on sessions for all using (auth.uid() = user_id); -- Commentaires sur sessions partagées create table session_comments ( id uuid primary key default gen_random_uuid(), session_id uuid references sessions not null, user_id uuid references auth.users not null, username text, quality int, comment text, created_at timestamptz default now() ); alter table session_comments enable row level security; create policy "Anyone can read comments" on session_comments for select using (true); create policy "Users manage own comments" on session_comments for all using (auth.uid() = user_id);
Étape 2 — Configurer le fichier HTML
Ouvre surf-journal.html et remplace les deux lignes en haut :
const SUPABASE_URL = 'https://xxxxx.supabase.co';
const SUPABASE_KEY = 'eyJhbGc...';
Étape 3 — Mettre en ligne (Netlify)
1. Va sur netlify.com → "Add new site" → "Deploy manually"
2. Glisse-dépose ton fichier surf-journal.html
3. Partage l'URL avec tes potes !
Étape 4 — Extension Chrome (données meteo.nc)
Pour les prévisions meteo.nc en temps réel, installe l'extension qui capte automatiquement le token :
⬇ Télécharger nc-token-extension-v10.zip
Puis : chrome://extensions → Mode développeur → Charger l'extension non empaquetée → sélectionner le dossier.
Visite meteo.nc une fois → le token est capté automatiquement. Sans extension : voir la section Token dans Mon profil.
