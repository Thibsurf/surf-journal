1
Télécharger le fichier ZIP de l'extension
Pas besoin du Chrome Web Store — installation manuelle en 2 clics
ℹ️
L'extension n'est pas sur le Chrome Web Store — elle est fournie directement ici. C'est normal et sécurisé : elle ne fait qu'une seule chose, capturer votre token meteo.nc.

Cliquez sur le bouton ci-dessous pour télécharger le fichier ZIP :

⬇️ Télécharger nc-token-extension-v10.zip
💡
Où est-il téléchargé ? Dans votre dossier Téléchargements (accessible depuis l'explorateur de fichiers). Ne le déplacez pas encore.
2
Décompresser le ZIP
Extraire le dossier qui contient l'extension

Le fichier ZIP doit être décompressé avant installation. Voici comment :

  • 1
    Ouvrez votre dossier Téléchargements
  • 2
    Faites un clic droit sur nc-token-extension-v10.zip
  • 3
    Cliquez sur « Extraire tout » (Windows) ou « Ouvrir » (Mac)
    Un dossier nc-token-extension-v10 apparaît — gardez-le là, ne le supprimez pas !
⚠️
Ne supprimez pas ce dossier après l'installation. Chrome en a besoin pour fonctionner. Vous pouvez le ranger dans Documents si vous voulez.
3
Installer dans Chrome
Activer le mode développeur et charger l'extension
🔓
« Mode développeur » — ce nom fait un peu peur, mais c'est juste une option de Chrome qui permet d'installer des extensions en dehors du Chrome Web Store. Cela ne change rien à la sécurité de votre navigateur.

Ouvrez la page des extensions de Chrome :

🔗 chrome://extensions

Si le lien ne fonctionne pas, copiez chrome://extensions dans la barre d'adresse.

✅
L'extension NC Surf Token apparaît dans la liste — c'est bon ! Vous pouvez épingler son icône 🧩 dans la barre Chrome pour y accéder facilement.

Questions fréquentes
⏱ Le token expire — que faire ? ›
Le token meteo.nc dure environ 25–30 minutes. Quand il expire :

  • Allez sur meteo.nc (juste charger la page suffit)
  • L'extension capture automatiquement le nouveau token
  • Revenez sur le site Surf NC et rechargez-le
💡
Astuce : gardez un onglet meteo.nc ouvert en arrière-plan. Quand le token expire, cliquez sur « Capturer / Renouveler » dans l'extension — elle rouvre meteo.nc et capture le nouveau token en quelques secondes.
❌ L'extension dit "Aucun token capturé" ›
Cela signifie que l'extension n'a pas encore vu de requête vers meteo.nc. Solutions :

  • Visitez meteo.nc et attendez le chargement complet
  • Cliquez sur une prévision ou une carte pour déclencher des requêtes
  • Revenez sur la popup de l'extension — le token devrait apparaître
🔄 Le site affiche encore "GFS" au lieu de "meteo.nc" ›
Le site lit le token via l'extension au chargement. Si vous avez installé l'extension après avoir ouvert le site :

  • Rechargez le site Surf NC (F5 ou Ctrl+R)
  • Si toujours GFS : vérifiez que le token est vert dans la popup d'extension
  • Cliquez sur le petit bouton 🔑 sur le site Surf NC et collez manuellement le token si nécessaire
🖥️ Est-ce que ça fonctionne si j'ouvre le site en local (fichier HTML) ? ›
Oui, depuis la version 10 de l'extension. Pour que ça marche :

  • Allez dans chrome://extensions
  • Cliquez sur Détails de l'extension NC Surf Token
  • Activez « Autoriser l'accès aux URL de fichiers »
🔒 Est-ce sécurisé ? Que fait l'extension avec mes données ? ›
L'extension fait une seule chose : capturer le token Bearer que votre navigateur envoie déjà à meteo.nc, et le transmettre au site Surf NC.

Elle ne stocke aucun mot de passe, ne lit pas vos emails, n'accède pas à vos fichiers, et ne communique qu'avec :
  • meteo.nc (pour capturer le token)
  • le site Surf NC (pour lui transmettre)
  • le worker Cloudflare (pour synchroniser entre appareils)
🔍
Le code source est entièrement visible dans le dossier nc-token-extension-v10 — vous pouvez l'ouvrir avec n'importe quel éditeur de texte.
📱 Ça marche sur téléphone ? ›
Non — les extensions Chrome ne sont disponibles que sur Chrome ordinateur (Windows, Mac, Linux). Sur téléphone, vous pouvez coller le token manuellement via le bouton 🔑 du site, mais c'est moins pratique.
