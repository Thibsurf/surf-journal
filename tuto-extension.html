Installation (une seule fois)

1

Dézipper dans un dossier fixe

Dézippe nc-token-extension.zip dans un endroit permanent, ex: Documents/nc-token/.
⚠ Ne supprime pas ce dossier après installation.

2

Ouvrir le gestionnaire d'extensions

Dans Chrome, Edge ou Brave, tape dans la barre d'adresse :
chrome://extensions puis Entrée.

3

Activer le mode développeur

En haut à droite de la page, active l'interrupteur Mode développeur.

4

Charger l'extension

Clique Charger l'extension non empaquetée → sélectionne le dossier dézippé (celui qui contient manifest.json).

5

Épingler dans la barre

Clique l'icône 🧩 à droite de la barre d'adresse → trouve meteo.nc Token → clique 📌.
L'icône 🔑 apparaît dans ta barre.

Après installation — l'extension ouvre automatiquement meteo.nc en arrière-plan dans les 2 premières secondes pour capturer le premier token. Tu n'as rien à faire.

Utilisation au quotidien

A

Rien à faire — c'est automatique

L'extension renouvelle le token toutes les 6h. La popup affiche le prochain renouvellement prévu.

B

Si le token expire (rare)

Clique l'icône 🔑 → bouton 🔄 Renouveler maintenant.
L'extension ouvre meteo.nc (~12s), capture le token, ferme l'onglet.

C

Copier et coller dans Surf NC

Clique 🔑 → 📋 Copier → dans Prévisions NC clique 🔑 → colle → Enregistrer.
