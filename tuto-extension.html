🔑 Extension meteo.nc Token v3.0

Installation rapide · Refresh automatique · Synchronisation Surf NC
⚡ Important : l’extension capture automatiquement le token sur meteo.nc et le maintient à jour via refresh en arrière-plan.

⚙️ Fonctionnement

✔ Capture automatique du token sur meteo.nc
✔ Refresh en arrière-plan (toutes les X heures)
✔ Stockage local dans le navigateur
✔ Synchronisation vers Surf NC
✔ Backup sur Supabase

🔄 Mise à jour du token

- ✔ Nouveau token détecté → mise à jour automatique
- ♻ Token identique → seule la date est mise à jour
- 🔄 Refresh périodique pour forcer renouvellement si nécessaire
- ❌ Si capture échoue → dernier token conservé

🧠 Logique intelligente

✔ Refresh automatique en arrière-plan
✔ Ouverture invisible de meteo.nc si nécessaire
✔ Détection du token dès qu’il est disponible
✔ Évite les doublons et mises à jour inutiles

☁️ Synchronisation Surf NC

- Token stocké localement (source principale)
- Surf NC lit directement ce token
- Supabase sert de sauvegarde distante
- Synchronisation automatique multi-appareils

⚠️ Important

Le token dépend de meteo.nc.

Si le site ne régénère pas de session : → le token peut rester identique même après refresh

Le bouton “actualiser” force une tentative de renouvellement.
