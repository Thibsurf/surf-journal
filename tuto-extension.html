🔑 Extension — meteo.nc Token

Installation en 3 minutes · Une seule fois
Pourquoi ? L'app Prévisions NC utilise l'API meteo.nc qui requiert un token JWT. Ce token expire toutes les 24-48h. Cette extension Chrome le capture automatiquement à chaque visite de meteo.nc.
📦

nc-token-extension.zip

⬇ Télécharger

Installation

1

Dézipper dans un dossier fixe

Dézippe nc-token-extension.zip dans un endroit permanent, par exemple Documents/nc-token/. ⚠ Ne supprime pas ce dossier ensuite.

2

Ouvrir le gestionnaire d'extensions

Dans Chrome (ou Edge, Brave), tape dans la barre d'adresse :
chrome://extensions puis Entrée.

3

Activer le mode développeur

En haut à droite de la page, active l'interrupteur Mode développeur.

4

Charger l'extension

Clique Charger l'extension non empaquetée → sélectionne le dossier dézippé (celui qui contient manifest.json).

5

Épingler dans la barre Chrome

Clique sur l'icône 🧩 à droite de la barre d'adresse → trouve meteo.nc Token → clique 📌 pour l'épingler. L'icône 🔑 apparaît dans ta barre.

Utilisation au quotidien

A

Visite meteo.nc

Le token est capturé automatiquement en arrière-plan à chaque visite.

B

Clique l'icône 🔑 épinglée

La popup affiche le token avec un bouton 📋 Copier.

C

Colle dans l'app Prévisions

Dans Prévisions NC, clique 🔑 en haut → colle (Ctrl+V) → Enregistrer.

Fréquence de renouvellement
Le token expire toutes les 24-48h. Il suffit de visiter meteo.nc (ce qu'on fait naturellement) pour qu'il se renouvelle automatiquement.
