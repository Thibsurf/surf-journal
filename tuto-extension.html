Installation

1

Dézipper dans un dossier fixe

Dézippe nc-token-extension.zip dans un endroit permanent, par exemple Documents/nc-token/. Ne supprime pas ce dossier après installation.

2

Ouvrir les extensions Chrome

Dans Chrome, Edge ou Brave, tape : chrome://extensions

3

Activer le mode développeur

Interrupteur Mode développeur en haut à droite.

4

Charger l'extension

Bouton Charger l'extension non empaquetée → sélectionne le dossier dézippé.

5

Épingler dans la barre (optionnel)

Clique 🧩 → trouve meteo.nc Token → 📌 pour épingler. Utile pour voir l'état mais pas nécessaire au fonctionnement.

Après installation — dans les 2 secondes l'extension ouvre meteo.nc en arrière-plan, capture le token, et le pousse dans l'app Surf NC. Tu n'as plus rien à faire. Ouvre simplement les Prévisions NC — le token sera déjà là.
