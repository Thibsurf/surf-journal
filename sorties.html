⚖️ Comment ça marche ?
💰 Dépense sur chaque carte → ajoute une dépense (essence, repas, matériel…) partagée entre les inscrits.
👤+ → ajoute un participant sans compte (par prénom) pour inclure quelqu'un dans les dépenses.
➕ Dépense hors sortie ci-dessous → pour un frais non lié à une sortie précise.
⚖️ Bilan → solde de chaque personne + virements minimaux pour tout solder.
✓ Payé sur un transfert → enregistre qu'un remboursement a eu lieu, le solde se met à jour.
💸 Remboursement A→B → enregistre manuellement un paiement entre deux personnes quelconques.
🔗 Alias de noms → relie un prénom saisi manuellement (ex: "Thib") à un compte, pour que les anciennes dépenses soient comptées correctement.
➕ Ajouter une dépense hors sortie / Remboursement
ℹ️ Dépense rattachée à la sortie la plus récente — visible dans le bilan ⚖️.
Pour un remboursement direct entre deux personnes, clique 💸 Remboursement A→B.
